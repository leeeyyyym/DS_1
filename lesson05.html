서비스의 데이터 활용을 해석하고 확장하기 ✨

3~4차시 조별 이젤패드 활동 결과를 참고하되, 데이터의 선택·활용 해석·확장 아이디어는 자신의 판단과 근거로 작성합니다.

💭 오늘의 탐구 질문
“이 서비스는 어떤 데이터를 어떻게 활용하며, 나는 이를 어떻게 확장할 수 있을까?”
오늘의 목표 ①서비스 선정 이유, 핵심 데이터와 활용 방법을 자신의 말로 설명한다.
오늘의 목표 ②기존 데이터를 활용한 새로운 기능 또는 개선 아이디어를 제안한다.

1. 서비스 선정 및 선정 이유 📝

조에서 선정한 서비스는 같아도, 선정 이유는 자신의 관점에서 정리합니다.

🍔 예시 · 배달 앱
주문, 검색, 위치, 리뷰 등 다양한 데이터가 여러 기능과 연결되어 있어 데이터가 실제 서비스에서 어떻게 활용되는지 살펴보기 적절하다.
※ 예시의 표현을 그대로 옮기기보다, 우리 조 서비스의 특징에 맞게 작성합니다.

2. 서비스 데이터 식별 🔎

조별 활동에서 찾은 데이터 중 서비스의 특징을 잘 보여준다고 판단한 데이터를 선택하고 구체화합니다.

선정한 데이터구체적인 데이터 항목이 데이터를 선택한 이유
🍔 예시 · 배달 앱
선정한 데이터: 주문 기록
구체적인 항목: 주문 메뉴, 주문 시각, 주문 금액, 주문 음식점
선택 이유: 사용자가 실제로 무엇을 언제 주문했는지 보여주므로 서비스 이용 특징을 파악하는 데 도움이 된다.

3. 데이터 활용 방법 설명 💡

단순히 “추천에 사용된다”라고 쓰지 말고, 어떤 데이터의 어떤 특징을 이용해 어떤 결과를 제공하는지 설명합니다.
데이터연결되는 서비스 기능활용 방법 설명
🍔 예시 · 배달 앱
데이터: 주문 기록 → 기능: 음식 추천
활용: 이전에 자주 주문한 음식 종류와 주문 시간대 등을 참고해 사용자가 관심을 가질 가능성이 높은 음식이나 음식점을 추천하는 데 활용할 수 있다.

4. 가장 중요한 데이터 판단 ⭐

🍔 예시 · 배달 앱
가장 중요한 데이터: 주문 기록
근거: 사용자의 실제 선택이 누적된 데이터이므로 개인별 선호를 파악하는 데 활용할 수 있다.
없다면: 개인의 과거 이용 특징을 반영한 추천이 어려워질 수 있다.

5. 확장 아이디어 제시 🚀

제안하는 기능 / 개선 아이디어데이터를 어떻게 활용할 것인가?기대 효과
🍔 예시 · 배달 앱
활용 데이터: 주문 기록 + 주문 시각 + 현재 위치
제안 기능: 상황별 빠른 메뉴 추천
데이터 활용: 과거 주문 기록과 주문 시각, 현재 위치를 함께 고려해 지금 주문하기 적절한 메뉴를 우선 제시한다.
기대 효과: 사용자가 메뉴를 탐색하는 시간을 줄일 수 있다.
※ 실제 서비스에 이미 존재하는 기능인지보다 데이터와 아이디어가 논리적으로 연결되는지가 중요합니다.

6. 확장 아이디어 타당성 점검 🧭

데이터 연결제안한 기능에 필요한 데이터인가?
실현 가능성서비스 안에서 어떤 방식으로 구현할 수 있을까?
사용자 가치누구에게 어떤 도움이 될까?
🍔 예시 · 타당성 점검
데이터 연결: 주문 기록과 시각 정보가 추천 기준과 연결되는가?
실현 가능성: 기존 서비스 이용 과정에서 생성되는 데이터를 활용할 수 있는가?
사용자 가치: 사용자가 선택하는 시간을 줄이는 데 도움이 되는가?

7. 최종 보고서 요약 ✍️

🍔 예시 · 최종 요약
배달 앱은 주문과 탐색 과정에서 다양한 데이터를 활용한다. 나는 주문 기록이 사용자의 실제 선택을 보여준다는 점에서 중요하다고 보았다. 주문 기록과 주문 시각, 위치 데이터를 함께 활용해 상황별 빠른 메뉴 추천 기능을 제안했으며, 이를 통해 사용자의 탐색 시간을 줄일 수 있을 것으로 생각한다.
