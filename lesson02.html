서비스 속 데이터 찾기 ✨

지난 시간에 선정한 서비스를 바탕으로, 조 안에서 꼬리잡기 방식으로 기능과 관련 데이터를 최대한 넓게 찾아봅니다.

💭 오늘의 탐구 질문
“이 서비스에서는 무엇을 할 수 있고, 그 과정에는 어떤 데이터가 필요할까?”
오늘의 목표 ①서비스에서 사용자가 할 수 있는 일을 찾아 주요 기능을 선정한다.
오늘의 목표 ②기능과 관련된 데이터를 조원들과 중복 없이 폭넓게 식별한다.

1. 우리 조 서비스 확인 🌼

2. 꼬리잡기 ① · 이 앱에서 무엇을 할 수 있을까? 🔗

규칙 · 한 번에 한 가지씩 · 앞사람과 겹치지 않게 · 생각이 안 나면 PASS 가능 · 앞사람의 아이디어를 보고 확장해도 됨

조원 순서대로 돌아가며 이 서비스에서 사용자가 할 수 있는 일을 하나씩 적습니다. 2~3바퀴 진행합니다.

3. 비슷한 것끼리 묶고 주요 기능 정하기 🧩

앞에서 나온 행동 중 비슷한 것끼리 묶어 이름을 붙입니다. 이 묶음을 이번 활동에서 ‘주요 기능’으로 봅니다.

비슷하게 묶은 행동우리 조가 붙인 기능 이름

4. 꼬리잡기 ② · 기능에는 어떤 데이터가 필요할까? 💡

기능 하나를 정한 뒤 조원 순서대로 앞사람과 겹치지 않는 데이터를 하나씩 추가합니다. 질문은 “이 기능이 작동하려면 서비스는 무엇을 알고 있어야 할까?”입니다.
주요 기능조원들이 찾은 관련 데이터
예시
영상 추천 → 시청한 영상, 검색어, 좋아요 기록, 구독 정보, 영상별 시청 시간
※ 실제 내부 알고리즘을 맞히는 활동이 아니라, 기능을 보고 필요한 데이터를 합리적으로 추론하는 활동입니다.

5. 오늘 발견한 데이터 모아보기 ⭐

🌟 오늘의 핵심

하나의 서비스에는 다양한 데이터가 존재하고, 하나의 데이터가 여러 기능과 연결될 수도 있습니다. 다음 시간에는 오늘 찾은 ‘검색 기록’, ‘주문 기록’, ‘위치 정보’ 같은 표현을 실제로 기록 가능한 값 수준으로 더 구체화합니다.
