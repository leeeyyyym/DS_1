3~4차시에 걸쳐 이젤패드에서 조별로 활동합니다. 서비스만 선정한 조도 주요 기능 선정부터 시작해, 기능과 관련된 데이터를 찾고 실제 기록 가능한 값과 생성·수집 과정까지 구체화합니다. 이 페이지에는 조별 활동 결과만 정리합니다.

💭 오늘의 탐구 질문
“이 서비스의 주요 기능에는 어떤 데이터가 필요하고, 그 데이터는 어떤 값으로 만들어지고 수집될까?”
오늘의 목표 ①조별 이젤패드 활동으로 주요 기능과 관련 데이터를 찾는다.
오늘의 목표 ②데이터를 실제 기록 가능한 값으로 구체화하고 생성·수집 방식을 설명한다.

4. 기능별 데이터 꼬리잡기 💡

선정한 기능 하나씩 돌아가며, 그 기능이 작동하려면 필요한 정보를 앞사람과 겹치지 않게 적습니다.

질문: “앱이 이 기능을 제공하려면 무엇을 알고 있어야 할까?”
주요 기능관련되어 있을 것 같은 데이터
🍔 예시

배달 현황 확인 → 주문 시각, 음식점 위치, 배달 위치, 현재 배달 상태

5. 데이터 구체화하기 🔍

‘사용자 정보’, ‘검색 기록’처럼 넓은 표현에서 멈추지 않습니다. 컴퓨터에 실제 값으로 기록한다면 무엇이 기록될 수 있을까?를 생각합니다.
앞에서 찾은 데이터더 구체적인 데이터 항목
🍔 예시

위치 정보 → 현재 위치, 출발 위치, 목적지 등

7. 조별 결과 정리 ⭐

주요 기능구체화한 데이터 항목어떻게 생성·수집되는가?
🌟 오늘의 핵심

서비스의 기능은 여러 데이터와 연결되고, ‘검색 기록’ 같은 하나의 데이터도 실제로는 검색어·검색 시각·클릭 결과처럼 여러 구체적인 값으로 나누어 기록될 수 있습니다. 다음 시간부터는 이 조별 결과를 참고해 개인 보고서를 작성합니다.
